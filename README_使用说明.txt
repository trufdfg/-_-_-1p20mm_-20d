图表数据代码复现包_统一1p20mm_含20d

本复现包用于生成论文中的图1–图6。每个图或子图的数据与代码已分别放入独立文件夹中。

重要校正说明：原数据整理表中出现的1.13 mm液池厚度标签为记录误写。经实验记录复核后，全部THz-TDS液体样品池有效厚度统一为1.20 mm。本复现包已将带有cell_thickness或cell_thickness_mm字段的数据统一校正为1.20 mm，并相应修改图2e、图6及复合图脚本，不再按液池厚度分层或将厚度作为潜在混杂变量讨论。

运行方式：
1. 安装依赖：pip install -r requirements.txt
2. 运行全部图：python 00_run_all.py
3. 单独运行某一图：进入相应文件夹后运行 python plot.py

注意：20 d样品有THz记录但无KF参考值，仅用于趋势观察，不参与监督训练、测试、误差评价或梯度留一验证。
